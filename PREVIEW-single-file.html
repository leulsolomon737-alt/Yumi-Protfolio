How a job runs

Four steps, start to delivery.

  1. 01

    Brief

    You send footage, the goal and the platform. I come back with what I think the cut should be.

  2. 02

    First cut

    Structure and pacing only, no polish. This is where we agree on the shape before anyone spends time on details.

  3. 03

    Polish

    Colour, sound, captions, graphics. Two rounds of notes are included.

  4. 04

    Delivery

    Exported for the platform it's going to, with the project file if you want it.

About

I'm Leul, a video editor based in Addis Ababa. I edit every day for an education brand, which means I've spent a lot of hours learning what actually holds attention on a phone rather than what looks clever in a timeline.

I work in short-form mostly, and I care about the unglamorous parts: frame-accurate cuts, readable captions, audio that doesn't peak. If a video needs a script before it needs an edit, I can write that too.
